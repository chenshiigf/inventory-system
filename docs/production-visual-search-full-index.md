## 本地运行保护

新增专用运行器，复用现有 `VisualService.rebuild`、Provider、内容缓存和独立索引 schema；没有增加生产接口，也不需要 SSH、服务器构建或生产服务变更。

- 开始前比较已验收报告的来源 ID、命名空间、镜像指纹、index key、模型、维度和版本；检查原 10 款仍为 ready。
- 镜像必须 `scope=full`、`published=true`、2414 款。所有计划重新读取本地图片 SHA256，不同步商品资料或改写镜像。
- 每批最多 100 款，串行调用，原有 1 秒间隔保持，自动重试强制关闭。第一批完整性验收正常后自动继续。
- 每次请求前检查来源文件是否改变、累计费用和未确认的请求；每款处理后写入 checkpoint。成功缓存立即持久化，重复内容复用；在同一次运行中不自动重试失败商品。
- 连续 3 次同类 API 错误、返回向量维度/数值异常、响应格式异常、来源变化，立即停止后续调用。任一批未通过验收也停止，不跳过失败后继续全量。
- 保存每批原始结果、ID/SHA job manifest、向量检查及累计用量。原查询、人工确认以及已有成功向量只检查指纹，不删除或修改。

### 10 元停止阈值

本工具提供**本地按返回 Token 估算的停止保护**，并非百炼账户或信用卡的硬性扣费上限；不影响其他任务或账户自行发起的调用，也不读取账单和免费额度。

图片 ¥0.0018/千 Token、input ¥0.0007/千 Token；使用 Decimal 逐次累计本次授权后写入账本的用量，每次发送前要求“已累计估算 + 未知用量保守计入 + 下一次 ¥0.10 预留”不超过 ¥10。超过则不再发送。

预留依据：[官方模型信息](https://help.aliyun.com/zh/model-studio/qwen3-vl-embedding)给出的最大输入长度 32,000 Token，以较高图片费率估算为 ¥0.0576，再保守扩大到 ¥0.10。单次实际返回费用超过 ¥0.02 视为异常并停止；缺少/负数/非整数/总量不一致的 usage 立即停止，未知请求按 ¥0.10 保守计入，不将缺失用量当作免费。

原价来源：[官方多模态向量 API](https://help.aliyun.com/zh/model-studio/multimodal-embedding-api-reference)。只接受本次核对的费率；发现价格、模型或请求形态变化时应停止并重新核对，不能宣称该保护能约束供应商异常计费。

### 中断续建

每次付费请求发出前先持久化对应商品及图片 SHA 的 `inflight`。正常完成后内容缓存、商品关系和用量均保存；重启重新从 SQLite 账本累计费用，不重置本次预算。

如果进程在未知请求状态下终止：已有成功缓存可继续复用；没有缓存的历史 `inflight` 拒绝自动重复调用，先核对请求结果，避免把未知成功当作失败重新付费。网络错误无返回用量同样停止，先检查。不得自行删除 checkpoint 来绕过预算或历史请求检查。

## Windows 命令

在 `D:\inventory-system` 执行，仅在已经得到完整授权后使用：

```powershell
api/.venv/Scripts/python.exe api/scripts/index_production_catalog.py --execute-authorized-full --load-local-env
```

本地进程安全加载 `api/.env`，不输出密钥。只读取本地镜像并调用用户已授权的百炼端点，不访问生产服务器。默认报告目录：

```text
api/data/visual-search/phase17/full/
  state.json             # 来源、预算基线、保护指纹、inflight、批次检查点、最终统计
  batch-001.json         # 第一批运行及向量、ID/SHA、用量验收
  batch-002.json
  ...
```

向量与商品关系继续使用原独立 `production-indices/production-<来源指纹>/index.db`。整个数据、图片、向量、checkpoint、密钥目录均被 Git 忽略。

只读查看进度（不调用 AI）：

```powershell
Get-Content -Encoding utf8 api/data/visual-search/phase17/full/state.json
```

完整原始逐商品 ID/SHA 仍在私有本地报告及 job manifest 中，不提交 Git。普通 `visual_search.py index` 不会自动应用此专用全量保护；这次自动全量执行只使用上述运行器。
